# SQL & PostgreSQL — Learning Repository

Solutions and notes from my PostgreSQL learning process.
Part of a structured path toward backend development with Supabase.

## Contents

- `01-basics/` — SELECT, WHERE, ORDER BY, basic filtering
- `02-joins/` — INNER, LEFT, RIGHT, FULL joins
- `03-aggregation/` — GROUP BY, HAVING, aggregate functions
- `04-subqueries/` — subqueries and CTEs
- `05-window-functions/` — window functions
- `schema-design/` — my own database schema for a construction
  materials and site management app

## Sources

- [PGExercises](https://pgexercises.com/)
- [SQLBolt](https://sqlbolt.com/)
- [PostgreSQL official documentation](https://www.postgresql.org/docs/current/)

## Notes

Each file contains the task description as a comment, my solution,
and short notes on what I learned or got wrong.

The `schema-design/` folder is not from a course — it's my own
data model based on my background in construction and industrial
supply, built to practice real-world schema design.
