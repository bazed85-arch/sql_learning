# SQL & PostgreSQL — Learning Repository

Solutions and notes from my PostgreSQL learning process.
Part of a structured path toward backend development with Supabase.

## Contents

- `01-relational-model/` — relational model, normalization, keys and relationships
- `02-ddl-and-types/` — CREATE TABLE, data types, constraints
- `03-select-where/` — SELECT, WHERE, ORDER BY, LIMIT, NULL handling
- `04-joins/` — INNER, LEFT, RIGHT, FULL, SELF, CROSS
- `05-aggregation/` — GROUP BY, HAVING, aggregate functions
- `06-subqueries-cte/` — subqueries and common table expressions
- `07-window-functions/` — window functions
- `08-indexes-explain/` — indexes and query plans
- `09-transactions/` — transactions, ACID, isolation levels
- `project-construction-db/` — full schema and reports for a construction
  site and supply management database

## Sources

## Notes

Each folder contains my solutions with the task description as a comment,
plus a `notes.md` file with what I learned and what I got wrong.

The `project-construction-db/` folder is not from a course — it's my own
data model based on my background in construction and industrial supply,
built to practice real-world schema design.
